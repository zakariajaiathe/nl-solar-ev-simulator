Energy & cost detail

Run locally: save as index.html and open it, or serve the folder with python -m http.server 8000 and visit localhost:8000. No dependencies, no network calls — the only external request is the webfont, which degrades cleanly offline. Irradiance is a clear-sky model with Erbs diffuse split and monthly Dutch cloud factors, calibrated to 954 kWh/kWp for a south-facing 35° array at 52°N. Prices are per kWh excluding VAT. Supplier figures are July 2026 comparison-site values and should be checked against published tariff sheets before external use.
